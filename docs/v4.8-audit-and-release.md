# Sykabelajar v4.8.0 — Audit Remediation

This release addresses the highest-priority findings from the frontend audit against RPD v4.1.

## Fixed
- Cloudinary direct-upload `resourceType` initialization bug.
- Question option reads now include `is_correct` so answer keys survive edit/reopen.
- Assessment route is wired to a real attempt page.
- Server-authoritative attempt start/resume/save-answer/submit RPC contract.
- Server-side auto grading for objective types; essay/file-upload items enter manual grading.
- Manual finalize now uses a privileged RPC and audit reason.
- Registration wizard is three-stage: local twibbon generation, platform-specific social proof, completion/referral.
- Twibbon participant result remains local; organizer template remains the durable Cloudinary asset.
- Registration social proof stores platform + username metadata and validates platform/server-side.
- Referral codes and +5 Edu Coin referral ledger event are server-side and idempotent per registration.
- Admin dashboard uses `Promise.allSettled()` so one failed widget does not blank the whole control plane.
- Production version source is 4.8.0 and manifest remains the single release source.
- Static form modal behavior is retained.

## Required database migration
Apply the new migration once after the previous migrations:

`backend/migrations/0010_assessment_referral_hardening_v4_8.sql`

Do not re-run older migrations.

## Critical smoke flow
1. Login
2. Open a competition
3. Click Daftar
4. Generate twibbon locally from organizer template
5. Download
6. Step 2: choose Instagram/TikTok, enter username and matching URL
7. Step 3: submit registration
8. Verify PENDING or ACTIVE according to organizer plan/approval mode
9. Organizer reviews PENDING registrations
10. Move competition to LIVE
11. Participant clicks Mulai kompetisi
12. Attempt timer counts down from server `expires_at`
13. Answers autosave
14. Submit is idempotent
15. Objective questions auto-score; essay/file upload enters GRADING
16. Organizer finalizes with audit reason
